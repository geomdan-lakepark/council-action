# 더샵 검단레이크파크 입주예정자협의회

현재 공식 홈페이지와 단체민원 안내는 `geomdan-lakepark` Organization의 `geomdan-lakepark.github.io` 저장소에서 공동 관리합니다.

- 공식 홈페이지: https://geomdan-lakepark.github.io/
- 단체민원 안내: https://geomdan-lakepark.github.io/complaints/index.html
- 기존 단체민원 주소: https://geomdan-lakepark.github.io/council-action/

이 `council-action` 저장소의 페이지는 기존 주소로 방문한 사람을 공식 단체민원 안내로 자동 연결합니다. 자동 이동이 지원되지 않는 환경에서는 화면의 ‘민원 안내 보기’ 링크를 사용할 수 있습니다. 이 저장소에서는 별도의 문안 복사나 참여 화면을 제공하지 않습니다.

민원 내용·참여 마감은 공식 홈페이지 저장소에서 수정합니다. 마감은 `site.config.js`의 `campaign.enabled`, `campaign.deadline`을 기준으로 공식 민원 페이지에서 처리하므로, 기존 링크로 방문해도 같은 참여·종료 상태가 적용됩니다. 이전 민원 내용은 Git 이력에 보존되어 있습니다.
